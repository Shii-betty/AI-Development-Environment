# AI Development Environment

This repository contains the development environment and simple Hello World application created for the Artificial Intelligence course.

## Development Environment

- Development platform: Google Colab
- Programming language: Python
- Version control: GitHub
- Application: Hello World

## Project Description

The project demonstrates the setup of a Python-based development environment and the integration of source code with GitHub for version control. The environment was tested by developing and executing a simple Hello World application.

## Files

- `AI_Development_Environment.ipynb` – Google Colab notebook documenting the development environment and testing.
- `app.py` – Python source code for the Hello World application.
